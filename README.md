# Luhme 🔥

Luhme é um app criado para deixar seus momentos de leitura, estudo ou trabalho mais aconchegantes. Tenha o som de uma fogueira, músicas ambientes e uma atmosfera tranquila para relaxar, se concentrar e aproveitar melhor o seu tempo.

## ✨ Funcionalidades

* 🔥 Ambiente de fogueira
* 🎵 Música e sons ambientes
* ⏱️ Foco durante leitura, estudo ou trabalho
* 🌿 Interface minimalista e aconchegante

## 🛠️ Tecnologias

* Next.js
* React
* Tailwind CSS
* JavaScript

## 🚀 Como executar

Clone o repositório:

```bash
git clone https://github.com/Erick-Iuri/Luhme-Reading-app-.git
```

Entre na pasta:

```bash
cd Luhme-Reading-app-
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Depois, abra http://localhost:3000 no navegador.
